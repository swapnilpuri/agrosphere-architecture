## Forecast, anomaly and registry specification

`asOf` is an explicit UTC instant equal to target local midnight in the recorded IANA estate timezone. The target is the local date beginning there. Features use only revisions with source time **and** the applicable availability time strictly before `asOf`, and collectionDate before targetDate. Pick the highest consistent version known at cutoff; exact duplicate delivery has one effect. A conflicting identity/body or unresolved version hole yields INCOMPLETE_SOURCE; missing required observed date yields INSUFFICIENT_HISTORY. NONE never becomes zero. A void-only observed date may total zero with OBSERVED_ONLY coverage; it never proves no farm production.

Use the immediately preceding seven local calendar dates, not the last seven nonempty days. `WET_KG_MEAN_7_V1` and `DRY_KG_MEAN_7_V1` average exact sums of accepted source-rounded per-collection mass and round once HALF_UP to three decimal output digits. The comparable `*_LAST_DAY_V1` uses the immediately preceding date and the same relevant source eligibility. Dry eligibility is distinct from wet eligibility; pending DRC need not hide valid wet evidence. Do not mix totals from different source versions or timezones. Reject unsupported source/calculation policies instead of guessing. No weather feature or causal environmental/production join is authorized.

For the anomaly, freeze the forecast before loading labels. Optional `labelAsOf` must be the **next local midnight** after targetDate; otherwise anomaly is NOT_EVALUATED. Label eligibility uses both clocks at that later cutoff. Missing/incomplete actuals are UNSCORED; zero is valid when observed. Preserve the forecast cutoff even when the user requests later label evidence. Later corrections are new evidence, not edits to frozen evaluations. DST and UTC/date ordering are tested explicitly.

Each registered generated dataset has 63 target-calendar dates: seven warm-up, 28 train, 14 validation, 14 locked test. The model is fixed, with no tuning/test selection. Walk forward; earlier test labels may become later features only once available at that later cutoff. Retain dataset seed/generator/hash, source-contract hashes, availability policy, timezone, ordered date boundaries and code/algorithm parameters. Provide separate train/validation/test metrics, scored/withheld counts and reasons for mean/comparator, exact sum absolute error and MAE (six decimal HALF_UP, numerator and denominator retained). No MAPE or invented probability/confidence interval. Zero scored rows means unavailable metric, never a perfect score. For known generated anomaly cases, show expected/actual flags, confusion counts and unscored count; zero-denominator precision/recall is unavailable. Label anomaly truth as synthetic, not agronomic ground truth.

AI stores immutable DEMO_ONLY model/evaluation records and evaluation fingerprints. No mutable promotion, training HTTP endpoint, binary model, hosted registry or production eligibility. Model identity covers algorithm, target, features, rounding and policy versions; evaluation identity also covers dataset, cutoff/splits, metrics and source revisions. Deterministic replay/restart must yield the same identities/results. A changed policy creates a new version.

## Integration and data-flow design

1. Operations publishes its unchanged versioned snapshots. Analytics continues its accepted independent materialization; AI gets its own bounded private consumer. Neither reads another service's database. AI retains minimal collection ID/scope/version/date/status/mass/policy/source timestamp/fingerprint/availability metadata only, not workforce/actor/reason/raw envelopes. Validate the public event, then discard private fields. Commit journal/dedup atomically before ACK. Malformed/untrusted input gets minimal diagnostics; failed confirmation/storage does not ACK or silently drop. Reuse bounded confirmed-diagnostic/pause/restart patterns and prove broker privilege denial.
2. Infrastructure creates an owned generated evaluation corpus from accepted event shapes. Fixture-assigned availability is bound by the local manifest hash, not trusted from arbitrary public events. Corpus import is an offline fixture command restricted to the owned scope, with no public import route. Preserve separate actual receipt timestamps. Only the explicit generated mode may use simulated chronology; do not inject it into live observations or overwrite real clocks. A live history without sufficient pre-cutoff observations correctly withholds prediction.
3. Read-only AI endpoints serve forecast/anomaly and immutable model/evaluation records. A bounded POST assistant endpoint takes a closed intent, canonical block, cutoffs and approved evidence window; no conversation history or free text. It has no business mutation or provider side effect. Gateway adds **only `/api/v1/ai/**`** to AI, preserving existing JWT/CORS/limits/timeouts/correlation and all route behavior. No public metrics/admin/replay/import/SQL route.
4. Contracts defines `GET /api/v1/ai/estates/{estateId}/blocks/{blockId}/production/baselines`, block-scoped `GET .../models/{modelId}`, `GET .../evaluations/{evaluationId}` and `POST .../assistant`. Baseline requires asOf, explicit chronology mode/dataset identity and optional labelAsOf. Outputs include target/unit/timezone, sourceDataProvenance=SIMULATED, PREDICTED forecast provenance, OBSERVED_ONLY coverage, UNCALIBRATED uncertainty, mode, data cutoff, status/reasons and scoped typed source/model/evaluation refs. Decimal values use canonical decimal strings. Strict schema/size/query validation and 400/401/403/404/409/413/429/503 outcomes must be exemplified as applicable; no existence leak before access validation.
5. The assistant fetches bounded Analytics production history and optional environment [from,to) evidence through accepted APIs under the same caller. It states each evidence time, limits/truncation and conflicts. Environmental samples can be displayed/explained without attributing causation. A forecast explanation cites its earlier frozen feature set, not later corrected current totals. Evidence IDs are server-constructed; never fetch a user/model-provided URL. Inaccessible refs fail closed. No shared subject/scope cache or prompt/body logging.
6. Web independently pins generated clients. Selected block shows forecast/comparator, actual/residual/anomaly when eligible, dataset/cutoffs, model/evaluation drill-down, metrics and evidence composer. Evidence links open the matching authorized production/environment window or immutable AI record; anomaly link selects the canonical block. Show UNCALIBRATED/DEMO_ONLY/SIMULATED source and missing/denied/error states. Clear/cancel on block/account/scope changes; prevent stale response rendering and escape all text/links. Existing Cesium, Operations, telemetry and Analytics panels must continue to work.
