# POC scope
## This execution: Milestone 0 only
Twelve separate Git repositories; multi-root workspace; service ownership and ADRs; independently buildable foundations; API/event placeholders; infrastructure configuration; CI skeletons; a prioritized backlog. No GitHub remotes, pushes, deployments, infrastructure installation or complete-platform launch.

## Later POC capabilities
Milestone 1: estate and block identity, PostGIS geometry, synthetic rubber-estate GeoJSON and spatial queries. Milestone 2: Angular/Cesium terrain, polygon selection, KPI panels and gateway integration. Milestone 3: tapping, collection, DRC, inspections, MQTT simulation and alerts. Milestone 4: materialized analytics, forecasts/anomalies and evidence-linked assistant. Milestone 5: Unreal exploration, API integration and a supported VR interaction prototype.

Excluded now: business APIs, GIS implementation, AI models, gameplay/assets, production security certification, tenant isolation implementation, surveyed individual-tree inventory and cloud provisioning. No prior AgroSphere code is imported.
