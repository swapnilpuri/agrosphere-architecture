# Increment selection prompts

These retain the PDF's selectable increments while mapping to current ownership. Copy only the desired block. Selecting an increment limits the parent milestone scope; it does not close the parent milestone. Existing work is verified or corrected, not recreated.

accepted decisions. Apply the full milestone operating and approval rules, narrowed
to this increment and necessary dependencies.
